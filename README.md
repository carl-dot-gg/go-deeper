# go deeper

A bilingual (EN/FR) conversation card game that helps people have meaningful conversations.

## 🎮 Play

Open `index.html` in your browser or visit: (https://carl-dot-gg.github.io/go-deeper/)

## 📖 How it works

1. Pick a depth level (Light → Medium → Deep → Deeper)
2. Swipe through questions
3. Answer honestly
4. Go deeper together

## 🪨 Depth levels

| Stones | Level | Risk | Description |
|--------|-------|------|-------------|
| ● ○ ○ ○ | Light | Zero | Fun ice-breakers, anyone can answer |
| ● ● ○ ○ | Medium | Low | Personal stories, memories, values |
| ● ● ● ○ | Deep | Medium | Real vulnerability, takes courage |
| ● ● ● ● | Deeper | High | Core truths, the honest answer costs something |
